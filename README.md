## ✨ 产品简介

大学校园内代取快递、代买物品、代占座等跑腿需求频繁，但缺乏一个**可信**的校内互助渠道。「跑腿侠」围绕 **发布任务 → 接单跑腿 → 赏金托管 → 积累信用** 打造完整闭环，让需求方放心发布、让跑腿方安心接单。

## 🧩 核心功能

- **任务大厅**：搜索 + 分类筛选 + 赏金/时间排序，一键浏览可接任务
- **发布任务**：分类、赏金、取件/送达地点、截止时间、描述、图片、托管确认
- **任务详情**：按「角色 + 状态」动态显示 接单 / 送达 / 确认收货 / 评价 / 取消 / 申诉
- **我的订单**：我发布的 / 我接的，按状态筛选
- **消息通知**：系统与订单消息，未读角标、一键已读
- **信用中心**：信用分、等级成长、信用规则、勋章墙、排行榜（总榜/周榜）
- **个人中心**：钱包余额、实名认证、数据统计、演示数据重置

## 🛡 信任闭环（核心差异化）

1. **校园实名认证** —— 学号 + 姓名 + 校园卡（模拟），认证后展示徽章
2. **赏金托管** —— 发布即托管，完成并确认收货后放款，取消/超时原路退回
3. **信用分与等级** —— 初始 100 分，完成任务加分、违约扣分，等级成长
4. **双向评价** —— 双方星级 + 标签互评，差评联动扣信用分
5. **排行榜与勋章** —— 总榜/周榜，勤劳/准时/好评/全能等勋章

## 🎯 任务分类

`代取快递` · `代买餐食` · `代占座` · `代打印` · `代送文件` · `代拿外卖` · `拼单代购` · `其他`

## 🔄 订单状态机

```text
待接单 → 进行中 → 待验收 → 已完成 → 已评价
  │        │        │
  │        │        └── 发布者确认收货 → 放款 + 信用 +3/+4
  │        └── 跑腿取消(-5) / 超时退款(跑腿 -2)
  └── 发布者取消 → 赏金原路退回
```

## 🏅 信用体系

| 行为 | 分值 |
| :--- | :--- |
| 完成任务 | +3 |
| 准时送达 | +1 |
| 收到好评 | +1 |
| 超时未完成 | -2 |
| 跑腿取消订单 | -5 |
| 收到差评 | -5 |

等级：`新手(100)` → `靠谱(110)` → `达人(130)` → `大神(150)`；信用分低于 **95** 限制接单。

## 🛠 技术栈

- **框架**：React 18 + Vite
- **样式**：Tailwind CSS v4
- **路由**：react-router-dom（HashRouter，适配 GitHub Pages）
- **图标**：lucide-react
- **数据**：localStorage 本地持久化 + 种子数据（纯静态，无后端）

## 📁 项目结构

```text
campus-run/
├─ src/
│  ├─ pages/          # 页面：登录/首页/发布/详情/订单/消息/信用/我的
│  ├─ components/     # 通用组件：TaskCard / Shell / ui / ReviewModal
│  ├─ store/          # 全局状态 + localStorage 持久化
│  ├─ data/seed.js    # 演示种子数据
│  └─ lib/            # 信用规则、格式化工具
├─ deploy-github.mjs  # 一键部署到 GitHub Pages（走 API，绕开被墙的 git push）
├─ vercel.json        # SPA 路由重写（Vercel 部署备用）
└─ package.json
```
